# ShopSphere – E-Commerce Management System

ShopSphere is a full-stack e-commerce platform designed to provide users with a simple and convenient way to browse products, manage their shopping cart, and place orders online.

## Project Goal

The goal of ShopSphere is to provide a reliable online shopping platform where customers can browse and search for products, add items to their cart, and manage their orders.

The project is also designed to provide practical experience in building a real-world application using Java, Spring Boot, React, and PostgreSQL.

## Core Features

- User registration and login
- Product and category management
- Product browsing and search
- Shopping cart
- Order placement and management

## Technologies

### Frontend

- React

### Backend

- Java
- Spring Boot
- Spring Data JPA
- Spring Security
- REST API

### Database

- PostgreSQL

## Project Architecture

ShopSphere follows a layered architecture consisting of:

- Controller
- Service
- Repository
- Entity
- DTO
- Exception Handling
- Security
